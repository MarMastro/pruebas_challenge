# 📊 Análisis comparativo de tiendas

Este proyecto fue realizado como parte del curso de **Alura Latam**. Su objetivo es brindarle al Sr. Juan una recomendación de cual de sus tiendas debe vender con datos obtenidos mediante Python y librerías de visualización.

## 🎯 Propósito del Análisis

Se realizará un análisis comparativo entre cuatro tiendas.

- Ingresos totales por tienda.
- Categorías de productos más y menos vendidos.
- Calificaciones promedio de clientes.
- Productos más y menos vendidos.
- Costo de envío promedio por tienda.

## 📁 Herramientas utilizadas

- Python (Pandas, Matplotlib, Seaborn)
- Google Colab
- Visualización de datos

## 📌 Conclusión

De acuerdo a los datos análizados el Sr. Juan debería vender la Tienda 4:

- Menores ingresos.
- Menor volumen de ventas.
- Menor diversidad de productos vendidos.
